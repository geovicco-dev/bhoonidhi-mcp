Search ISRO's satellite archive in plain language.

02 · What it does

The portal wants exact tokens. You write a sentence.

Searching the old way means knowing the satellite token, the bounding box, and the date format up front. bhoonidhi-mcp lets the agent fill those in from what you said.

Command line — you supply every argument
# you need the exact SAT:SEN:PROD token and bounding box first bhd query create 2024-01-01 2024-01-14 \ --sat "Sentinel-2A:MSI:Level-1C" \ --minx 91.72 --maxx 92.04 \ --miny 25.42 --maxy 25.74
With bhoonidhi-mcp — you state intent
“Find Sentinel-2 scenes over Shillong from the first two weeks of January 2024.”

The agent resolves “Shillong” to a bounding box, matches “Sentinel-2” to the portal’s platform tokens, and runs the live search — then reports which results are actually downloadable.

04 · The tools

Fifteen tools, from discovery to download.

Each one is a thin adapter over the same client the bhd command line uses. Search, preview, and save are open to anyone. Downloading and cart use your own free Bhoonidhi account — the login is ISRO's, not this project's.

i

Search & discover · open to all

Explore the archive, resolve a place to a bounding box, run a live search, and preview what a download would fetch — with honest availability on every scene.

list_archive · resolve_location
search_scenes · preview_download
ii

Save & reuse · open to all

Persist a search to a reusable slug, then list, inspect, or remove it — the slug is what downloads and cart staging key off later.

save_query · list_queries
show_query · remove_query
iii

Download & cart · your ISRO account

Download open-access scenes in the background and follow the job to completion, or stage priced and on-order scenes to the Bhoonidhi cart.

auth_status · download_query
download_status · download_wait
cart_add · cart_list · cart_remove
05 · Configure your client

Point any MCP client at one command.

bhoonidhi-mcp runs over stdio: the client launches it as a subprocess and talks over stdin and stdout. Every setup comes down to “run this command.”

06 · How it's built

An adapter over the bhoonidhi-downloader SDK.

bhoonidhi-mcp does not talk to the portal directly. It calls the same client the bhd command line uses, so there is one place where portal logic lives.

Foundation

bhoonidhi-downloader

The SDK and bhd CLI: portal grammar, satellite tokens, availability classification, and downloads. bhoonidhi-mcp depends on it.

Python · CLI · the source of truth
This project

bhoonidhi-mcp

Turns natural language into structured portal queries and shapes the results for an agent. It adds the geocoder and the fuzzy satellite matching — nothing about the portal itself.

MCP · stdio · live search, save, download, cart

Availability is reported honestly. The server classifies every scene the same way the CLI does — Ready, Archived, On order, or Priced — so an agent can tell you what you can actually download before you try, instead of guessing from the scene name.

Why it exists. ISRO opened much of its Earth-observation archive to everyone, but the portal has no official SDK, so pulling data into a real workflow means clicking through a web form one scene at a time. This project — and the SDK under it — is a small, free, open-source bridge over that gap, with no money behind it and no motive beyond making open Indian EO data easier for the community to use. The roadmap follows what people actually need.
